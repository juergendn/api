SENVEND Terminal Test - Web Interface
======================================

Installation:
1. Entpacken Sie dieses ZIP-Archiv
2. Doppelklick auf START_WEBSERVER.bat
3. Browser öffnet sich automatisch auf http://localhost:5000

Konfiguration:
- Terminal IP-Adresse im Web-Interface eingeben (z.B. 172.16.1.202)
- Standard-Port: 11111

Verwendung:
- Quick Tests: 1 EUR, 2.50 EUR, 5 EUR Beträge
- Custom Test: Eigener Betrag mit optionaler Altersverifikation
- Live-Log zeigt alle Kommandos und Antworten

Systemanforderungen:
- Windows 10/11
- Keine Installation erforderlich (alles enthalten)
